# Harmit Patel — Junior Software Developer Portfolio

A responsive, static portfolio tailored for junior software developer applications. It uses semantic HTML, CSS, and a small amount of vanilla JavaScript; no build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve the `Personal-main` folder with any static web server.

## Current portfolio content

- Professional introduction aimed at junior software developer roles
- Skills grouped by frontend, backend, and data technologies
- A transparent showcase of the portfolio website itself
- About, learning approach, interests, and contact sections
- Responsive navigation, accessibility considerations, and social metadata

## Accuracy and customization checklist

- The listed technologies (HTML, CSS, JavaScript, React, Node.js, SQL/databases) reflect the owner's stated learning/working toolkit; the site does not claim expert-level proficiency.
- Only the portfolio website is currently presented as a project. Add further projects only after they have actually been built. For each project, add a truthful problem statement, features, technology list, source-code URL, and live demo URL.
- Confirm `hpharmit10@email.com` and the LinkedIn, Twitter, and Instagram URLs before applying for jobs.
- Add a résumé link only after placing a real résumé file in the project and checking the link.
- Verify the live URL and Open Graph image path before publishing.

## Project structure

- `index.html` — content, metadata, navigation, and sections
- `css/styles.css` — responsive design system and components
- `js/main.js` — mobile navigation and copyright year
- `images/` — original portfolio artwork and profile assets
